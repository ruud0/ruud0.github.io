Salida · Exit

A gate-area emergency exit run by the Beckhoff TwinCAT 3 controller my team built at TECNUN. The door logic on this page is a line-by-line port of our PLC code: 15 states, 37 transitions, one 10 ms scan, with a Raspberry Pi camera and a 3 s heartbeat watchdog. Hold the buttons the way you would on the real panel.

    How faithful this is

    Ported as written

    The state CASE, mTransitions, mOutputs, the R_TRIG / F_TRIG edges, the 5 s TON hold timers and FB_RPi_WATCHDOG run in the same order as MAIN, every 10 ms. Quirks are kept, not fixed.

    Wiring kept too

    The emergency button and the open limit switch are normally closed, so the code triggers on a falling edge. The stack light follows oLightGreen / Orange / Red; the beacon follows activate_alarm_global.

    Assumed for the twin

    The stepper takes 3 s end to end. The Pi bumps its heartbeat every 200 ms and sends a 1 s pulse when it flags a face. Passengers, security, ground staff and the airport are illustration: the PLC only drives the door, lights and alarm.

    Proposed, not in our code

    Two tiers of face flag. The Pi sends the PLC its detection pulse only for a wanted match, which evacuates the gate. A person of interest goes to security alone, so the door stays locked and iFacialDetec never fires. Our controller has a single tier.
